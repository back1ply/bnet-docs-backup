World of Warcraft

Original: https://community.developer.battle.net/documentation/world-of-warcraft

World of Warcraft provides APIs to access data for such things as player profiles, realms, achievements and other game information.

Before you can use the APIs, you must set up your client and secret as described in Getting Started.
