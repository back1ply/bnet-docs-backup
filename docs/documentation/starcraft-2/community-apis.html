StarCraft II Community APIs

Original: https://community.developer.battle.net/documentation/starcraft-2/community-apis

StarCraft II community APIs provide endpoints for StarCraft II player profiles.

Host Names

For all regions except China, the API host name follows the format {region}.api.blizzard.com, where {region} is one of us | eu | kr | tw. For China, the host name is gateway.battlenet.com.cn. For more information, see Regionality and APIs.

Parameters

Consider the following parameters when making StarCraft II API requests.

  • region: StarCraft II community APIs use the region parameter to set the host region in the Try It feature. Note: {region} does not affect StarCraft II responses, which use the :regionId parameter in requests. For more information, see Regionality and APIs.

  • accountId: You must have a player's profile ID to issue a GET /player/{accountId} request. You can retrieve this by issuing a GET /userinfo request. See Authorization Code Flow and OAuth APIs for more information.

  • regionId, realmId, and profileId: You can retrieve these parameters by issuing a GET /player/{accountId} request. For more information on region and realm IDs, see Regionality and APIs.

APIs

StarCraft II supports the following community APIs. For information about using the APIs, see Getting Started.

Profile API

Static

Returns all static SC2 profile data (achievements, categories, criteria, and rewards).
