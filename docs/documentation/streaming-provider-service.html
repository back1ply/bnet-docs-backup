Streaming Provider Service Summary

Original: https://community.developer.battle.net/documentation/streaming-provider-service

The Streaming Provider Service (SPS) enables Blizzard cloud gaming partners the ability to query the list of titles to which a player has access. This will enable the partner to enable or disable the ability to launch the title via the Battle.net launcher. The player will connect their accounts via Battle.net Oauth login and then approve the use of the account. The cloud gaming partner may then query the API with the user's account and will receive a list of eligible titles.

Get Playable Titles Flow

There are two main steps to get playable titles by account ID:

  1. Obtaining the access token using player's authorization code.
  2. Sending the request for the account to SPS.

Getting Started

This section summarizes the important Battle.net technologies you need to work with to connect to the Streaming Provider Service.

Get an OAuth access token to call the Streaming Provider Service

In your request, you will use the streaming.titles and openid scopes.

In the response, you receive a Bearer token (Oauth access token) specific to the user's account to use for the Streaming Provider Service (SPS).

Call the Get Playable Titles API using the access token for the Streaming Provider Service

Your client needs to implement handling transport errors, service errors, and successful API calls. For more information, see developer documentation for reference.

Requests to the SPS must include the Bearer token (api caller's OAuth authorization).

A successful response will include a list of all playable titles and sub-titles that the player has access to play.
