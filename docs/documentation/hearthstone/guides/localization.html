Hearthstone Localization

Original: https://community.developer.battle.net/documentation/hearthstone/guides/localization

All requests in the Hearthstone API include an optional locale parameter. Localization works as described in Regionality and APIs. The following example illustrates how to use an endpoint without a locale parameter:

https://us.api.blizzard.com/hearthstone/cards/52119-arch-villain-rafaam

The response will include information for all localized strings:

{
    ...
    name: {
        de_DE: "Erzschurke Rafaam",
        en_US: "Arch-Villain Rafaam",
        es_ES: "Archivillano Rafaam",
        es_MX: "Archivillano Rafaam",
        fr_FR: "Prince du mal Rafaam",
        it_IT: "Arcicattivo Rafaam",
        ja_JP: "大悪党ラファーム",
        ko_KR: "대악당 라팜",
        pl_PL: "Arcyzłoczyńca Rafaam",
        pt_BR: "Arquivilão Rafaam",
        ru_RU: "Суперзлодей Рафаам",
        th_TH: "สุดยอดวายร้ายราฟาม",
        zh_TW: "極盜天王拉法姆"
    },
    ...
}

Now, assume that you issue the same request with the locale parameter specified:

https://us.api.blizzard.com/hearthstone/cards/52119-arch-villain-rafaam?locale=en_US

The response includes only the text for that locale:

{
    ...
    name: "Arch-Villain Rafaam",
    ...
}

The following fields are localized in cards:

Field Description
name The name of the card.
text The in-game description of the card.
flavorText Extra text that is shown when hovering over a card in game.
image A URL containing an image of the card with localized text.

In addition, many of the elements returned by the /hearthstone/metadata endpoint include localized name fields.

The locale parameter is optional for most requests; however, you must specify a locale to:

  • search for text within the card using the textFilter parameter
  • sort a list of cards by name
