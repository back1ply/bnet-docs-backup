Hearthstone Game Modes

Original: https://community.developer.battle.net/documentation/hearthstone/guides/game-modes

Hearthstone cards come from one of several game modes: constructed, battlegrounds, mercenaries, and so on.

Specifying game mode in a search

When searching for cards or requesting details of a specific card, you can optionally supply a gameMode parameter:

https://us.api.blizzard.com/hearthstone/cards?locale=en_US&gameMode=battlegrounds
https://us.api.blizzard.com/hearthstone/cards/60036-mama-bear?locale=en_US&gameMode=battlegrounds
Valid gameMode parameter values include constructed, battlegrounds, mercenaries and more. These parameter values should match the slug for gameMode from the Card API Metadata. For the complete list of possible parameter values, check the Card API Metadata.

Constructed mode

Constructed is the default game mode. For general tips on finding constructed cards, see the Card Search section.

Battlegrounds mode

Battlegrounds cards have several key differences from constructed.
  • Battlegrounds card searches may return both collectible and uncollectible cards. Many cards are available in both constructed and battlegrounds mode, but a few, such as Mama Bear, are only in Battlegrounds.
  • Battlegrounds cards have a tavern tier, either a number 1-6, or hero.
  • Characters such as A. F. Kay and Millificent Manastorm are hero tier. They are playable characters rather than cards that can be drawn.
  • Non-hero Battlegrounds cards have special images that show their numeric tavern tier.
  • Some Battlegrounds cards also have upgraded versions with more powerful stats.
  • When you fetch data for a card that exists in both Constructed and Battlegrounds mode, Battlegrounds-specific information such as tavern tier or upgraded version will only be returned if your request includes gameMode=battlegrounds.

Search parameters specific to battlegrounds mode

  • Searching with gameMode=battlegrounds&tier=3 will return only cards that are in the third tavern tier.
  • Searching with gameMode=battlegrounds&tier=hero will return only Hero characters.
  • The minionType parameter may be supplied. Some minionTypes, such as murloc, are available in both Constructed and Battlegrounds modes. Other minionTypes, such as elemental, are not available in Battlegrounds mode.

Hearthstone Battlegrounds page

You can see the search terms in action by visiting the Battlegrounds page on the official Hearthstone website. As you update the filters with the controls, the page URL will automatically update with valid parameters that also work in conjunction with gameMode=battlegrounds.

Mercenaries

Mercenaries cards, like Battlegrounds cards, have additional data associated with them beyond constructed cards.
  • Mercenaries cards can be collectible or non-collectible.
  • Multiple cards can represent the same Mercenary, one card for each Mercenary skin variation. Each Mercenary has a skin variation that is considered the standard art for that Mercenary.
  • Mercenary cards have different attack and health values depending on what level the Mercenary is. These values for a given Mercenary level can be found in the "mercenaryHero" attribute on the card via the "statsByLevel" field. The attack and health value listed at the top level on the card are the values from the highest Mercenary level.
  • Mercenaries cards contain an additional field based on the type of card in the game mode. Mercenaries themselves include a mercenaryHero field containing the following:
    • The numeric mercId field gives the unique identifier for the mercenary. Different skins for the same mercenary will have the same mercId.
    • The boolean default field denotes whether a given card is the standard art for that Mercenary.
    • The statsByLevel field maps each level to the attack and health attributes a Mercenary has at that level.
    • The roleId field denotes which role a Mercenary fits into. You can find more about which roles exist and what their role IDs are by fetching metadata.
    • The craftingCost field notes the cost in coins to craft a given Mercenary using their unique Mercenary coins.

Search parameters specific to Mercenaries game mode

  • mercenaryId will return all Mercenaries cards that represent the Mercenary with the given ID.
  • mercenaryRole will return all Mercenaries cards that have the given Mercenary Role.
  • defaultMercenary will return all Mercenaries cards that match the requested boolean. 0 will return all cards that are NOT the default skin, while 1 will return the Mercenary card representing the default skin.

Hearthstone Mercenaries page

Much like Battlegrounds, you can see these custom search terms in action by visiting the Mercenaries page on the official Hearthstone website. As you update the filters with the controls, the page URL will automatically update with valid parameters that also work in conjunction with gameMode=mercenaries.
