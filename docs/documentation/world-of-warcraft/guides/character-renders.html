World of Warcraft Character Renders

Original: https://community.developer.battle.net/documentation/world-of-warcraft/guides/character-renders

Character render images are generated when a character logs out of World of Warcraft.

The list of available renders is located at the Character Media Summary endpoint:

/profile/wow/character/{realm-slug}/{character-name}/character-media

For more information, see the Character Media Summary endpoint documentation located on the World of Warcraft Profile APIs page.

Fallback Images

The character render CDN can serve fallback images for avatars that are requested but do not exist. To request a fallback image if an avatar does not exist, add the alt query parameter to the avatar image request.

Type Format Example
Query Parameter ?alt=/shadow/avatar/{race-id}-{gender-id}.jpg ?alt=/shadow/avatar/2-1.jpg

Race ID

You can request a list of available race IDs from the Playable Races Index endpoint:

/data/wow/playable-race/index

For more information, see the Playable Races Index endpoint documentation located on the World of Warcraft Game Data APIs page.

Gender ID

The list of available gender IDs are as follows:

Gender Gender ID
Male 0
Female 1

Sample Request

A formatted request will look as follows:

{avatar-url}?alt=/shadow/avatar/{race-id}-{gender-id}.jpg

Where:

  • avatar-url is the URL returned as avatar_url from the Character Media Summary endpoint
  • race-id is an ID returned as races[*].id from the Playable Races Index endpoint
  • gender-id is one of the gender IDs listed in the previous table

Example: https://render-us.worldofwarcraft.com/character/tichondrius/00/000000000-avatar.jpg?alt=/shadow/avatar/2-1.jpg
