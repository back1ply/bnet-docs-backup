Battle.net

Original: https://community.developer.battle.net/documentation/battle-net

Battle.net provides APIs to use for OAuth 2.0 authencation flows. Battle.net uses OAuth 2.0 to secure the game and community APIs that we provide.

For more information about OAuth, see Using OAuth.
