Diablo III

Original: https://community.developer.battle.net/documentation/diablo-3

Diablo III provides APIs to access data for such things as player profiles, seasons, and leaderboards.

Before you can use the APIs, you must set up your client and secret as described in Getting Started.

API Reference

  • Community APIs — Endpoints for Diablo III player profiles, acts, crafting, classes, skills, followers, and items.
  • Community APIs – CN — CN endpoints for Diablo III player profiles, acts, crafting, classes, skills, followers, and items.
  • Game Data APIs — Endpoints for Diablo III seasons, eras, and leaderboards.
