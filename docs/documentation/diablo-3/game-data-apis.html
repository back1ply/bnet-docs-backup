Diablo III Game Data APIs

Original: https://community.developer.battle.net/documentation/diablo-3/game-data-apis

Diablo III game data APIs provides endpoints for Diablo III seasons and eras.

Host Names

For all regions except China, the API host name follows the format {region}.api.blizzard.com, where {region} is one of us | eu | kr | tw. For China, the host name is gateway.battlenet.com.cn. For more information, see Regionality and APIs.

APIs

Diablo III supports the following game data APIs. For information about using the APIs, see Getting Started.

D3

Season Index

GET /data/d3/season/

Returns an index of available seasons.

Season

GET /data/d3/season/:id

Returns a leaderboard list for the specified season.

NameTypeRequiredDefaultDescription
:idintegeryes1The season for the leaderboard list; get a list of seasons with `GET /data/d3/season/`.

Season Leaderboard

GET /data/d3/season/:id/leaderboard/:leaderboard

Returns a the specified leaderboard for the specified season.

NameTypeRequiredDefaultDescription
:idintegeryes1The season for the leaderboard; get a list of seasons with `GET /data/d3/season/`.
:leaderboardstringyesachievement-pointsThe leaderboard to retrieve; get a list of leaderboards with `GET /data/d3/season/:id`.

Era Index

GET /data/d3/era/

Returns an index of available eras.

Era

GET /data/d3/era/:id

Returns a leaderboard list for a particular era.

NameTypeRequiredDefaultDescription
:idintegeryes1The era to retrieve; get a list of eras with `GET data/d3/era/`.

Era Leaderboard

GET /data/d3/era/:id/leaderboard/:leaderboard

Returns the specified leaderboard for the specified era.

NameTypeRequiredDefaultDescription
:idintegeryes1The era for the leaderboard; get a list of eras with `GET /data/d3/era/`.
:leaderboardstringyesrift-barbarianThe leaderboard to retrieve; get a list of leaderboards with `GET /data/d3/era/:id`.
