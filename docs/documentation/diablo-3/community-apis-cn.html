Diablo III Community APIs – CN

Original: https://community.developer.battle.net/documentation/diablo-3/community-apis-cn

The Diablo III community APIs provide China-specific endpoints for Diablo III profiles.

Diablo III Icons

Developers can fetch the images referenced by the D3 APIs by using the following URL template:

http://media.blizzard.com/d3/icons/<type>/<size>/<icon>.png.

where:

  • <type> indicates the type of resource referenced; it can either be items or skills.
  • <size> for items must either be small or large.
  • <size> for skills must be 21, 42, or 64. These values refer to the image size in pixels.

Host Names

In China, requests use the following formats:

  • API request paths: https://gateway.battlenet.com.cn
  • OAuth requests: www.battlenet.com.cn/{API path}

APIs

Diablo III supports the following APIs for the China region. For information about using the APIs, see Getting Started.
