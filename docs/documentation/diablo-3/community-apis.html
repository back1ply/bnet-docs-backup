Diablo III Community APIs

Original: https://community.developer.battle.net/documentation/diablo-3/community-apis

Diablo III community APIs provide endpoints for Diablo III player profiles.

Diablo III Icons

Developers can fetch the images referenced by the D3 APIs by using the following URL template:

http://media.blizzard.com/d3/icons/<type>/<size>/<icon>.png.

where:

  • <type> indicates the type of resource referenced; it can either be items or skills.
  • <size> for items must either be small or large.
  • <size> for skills must be 21, 42, or 64. These values refer to the image size in pixels.

Host Names

For all regions except China, the API host name follows the format {region}.api.blizzard.com, where {region} is one of us | eu | kr | tw. For China, the host name is gateway.battlenet.com.cn. For more information, see Regionality and APIs.

APIs

Diablo III supports the following community APIs. For information about using the APIs, see Getting Started.
