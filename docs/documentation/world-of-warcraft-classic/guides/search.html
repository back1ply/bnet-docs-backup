World of Warcraft Classic Search

Original: https://community.developer.battle.net/documentation/world-of-warcraft-classic/guides/search

The World of Warcraft game data APIs now support search functionality. Using a search endpoint returns a paginated subset of data that match your query criteria. This subset can contain a maximum of 1000 entries.

Note that currently only the realm and connected-realm document types are supported.

Querying Data

To perform a search operation on a set of data, use the following base URL pattern:

/data/wow/search/{documentType}?namespace={namespace}

This URL has no fields specified, and therefore will return a paginated result of all data at the specified document type, limited to 1000 entries. To query on specific fields, add query parameters with the corresponding field names.

/data/wow/search/{documentType}?namespace={namespace}&{field}={value}

This search will return only those entries that have a matching value in the specified field. For example, to query all connected realms that have a login queue, use the following:

/data/wow/search/connected-realm?namespace=dynamic-us&has_queue=true

Additionally, you can use nested field names to query complex data structures. For example, to query all connected realms in the US Eastern timezone:

/data/wow/search/connected-realm?namespace=dynamic-us&realms.timezone=America/New_York

You may also add multiple fields as separate query string parameters. For example, to limit results to the intersection of the two result sets above, add both fields to the query string:

/data/wow/search/connected-realm?namespace=dynamic-us&has_queue=true&realms.timezone=America/New_York

Special Parameters

Some query string parameters are reserved for special operations, such as:

parameter example description
tag
tags
_tag
_tags		 _tag=item Used only for media documents.
Specifies the type of media document (item, spell, creature-display, etc) to query.
_page _page=2 Specifies which page of search results to return. The default page is 1.
_pageSize _pageSize=500 Specifies the size of each page in the result. The default value is 100 and can support a minimum of 1 or a maximum of 1000.
orderby orderby=field1
orderby=field1:asc
orderby=field1:desc

orderby=field1:desc,field2:asc		 Accepts a comma-separated list of fields and sorts the result in order of those fields. :asc and :desc can be appended to each field to instruct the search endpoint to sort in ascending or descending order.
namespace namespace=dynamic-us The namespace of the document. For more information on namespaces see World of Warcraft Namespaces and World of Warcraft Classic Namespaces.

Operations

Additional search operations can be performed as follows:

operation example description
AND str=5&dex=10 An implicit AND operation is performed by multiple query parameters.
OR str=5||10
type=man||bear||pig		 An OR operation is performed by placing a pair of bars between two values.
NOT race!=orc A NOT operation is performed by using a combination of an exclamation mark and equal sign between two values. You can combine the NOT and OR operations in a single statement (for example, race!=orc||human).
RANGE str=[2,99]
str=(2,99)		 A RANGE operation is performed only on numeric field values by using either brackets (inclusive) or parentheses (exclusive) around comma-separated minimum and maximum values.
MIN str=[41,]
str=(41,)		 A MIN operation performs a minimum value check using the Range syntax.
MAX str=[,77]
str=(,77)		 A MAX operation performs a maximum value check using the Range syntax.
