World of Warcraft Classic Media Documents

Original: https://community.developer.battle.net/documentation/world-of-warcraft-classic/guides/media-documents

Media documents help with the discoverability of web assets related to request API resources. Media documents can link to web resources such as web-rendered images, player character renders (like those seen on the World of Warcraft website), and in-game assets (like spell or item icons).

The following example shows the media property present on an Item document, which links to a generic media document. The generic media document contains references to web resources associated with the parent document.

Sample Media Document

{
  "_links": {
    "self": {
      "href": "https://us.api.blizzard.com/data/wow/media/item/19019?namespace=static-us"
    }
  },
  "assets": [
    {
      "key": "icon",
      "value": "https://render-us.worldofwarcraft.com/icons/56/inv_sword_39.jpg"
    }
  ],
  "id": 19019
}

When consuming assets linked in media documents, we strongly encourage you to store copies of these resources on your own servers or other storage locations rather than linking directly to Blizzard resources.
