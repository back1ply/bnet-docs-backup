Using APIs

Original: https://community.developer.battle.net/documentation/guides

The APIs provide developers with tools to enrich any fan site with information about World of Warcraft, StarCraft II, Diablo III, and Hearthstone. Here are just a few ways developers can integrate API data into their websites:

  • Add World of Warcraft character achievements, guild information, and Mythic Dungeon leaderboards.
  • Display player profiles, ladder information, and match history for StarCraft II.
  • Retrieve Diablo III player hero information, season leaderboards, and character class and skill information.
  • Return information about Hearthstone cards and decks.

Before you can use our public APIs, you need to set up an OAuth client ID and secret. After that, check out our documentation and the API requests to access game and community data.
