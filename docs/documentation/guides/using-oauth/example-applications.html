Example Applications

Original: https://community.developer.battle.net/documentation/guides/using-oauth/example-applications

Battle.net provides the following example applications that illustrate using OAuth 2:

  • Java Signature Generator
  • Node.js Signature Generator
  • Ruby Signature Generator

The community has also created example applications that use OAuth 2. To see a collection of community examples, please visit the Blizzard API Discussion forum thread.
