Support for OpenID Connect

Original: https://community.developer.battle.net/documentation/guides/using-oauth/oidc-endpoints

The Battle.net OAuth Provider supports the OpenID Connect (OIDC) specification. The OAuth Provider implements IETF RFC 5785 to define a well-known endpoint. This standard discovery endpoint provides a convenient way to obtain the configuration of the OAuth Provider.

For more information about using the endpoint, see IETF RFC 8414 and OpenID Connect Discovery on the OpenID website. The OpenID website also provides a list of certified OpenID Connect implementations.

OpenID configuration endpoints

The configuration endpoints for the regions are:

  • US: https://oauth.battle.net/.well-known/openid-configuration
  • EU: https://oauth.battle.net/.well-known/openid-configuration
  • KR: https://oauth.battle.net/.well-known/openid-configuration
  • TW: https://oauth.battle.net/.well-known/openid-configuration
  • CN: https://oauth.battlenet.com.cn/.well-known/openid-configuration

Scopes

To fully use OpenID Connect (OIDC), you must request the openid scope for your clients. Doing so adds an additional id_token field to the JSON response from the OAuth Provider token endpoint. The id_token field is JWT-encoded and signed with the server private key. The OAuth Provider has a public JSON Web Key Set (JWKS) endpoint that returns a list of public keys. You can use these keys to verify that the id_token was signed from the Battle.net OAuth server.

JWKS endpoints

The JWKS endpoints are returned from the OpenID Configuration endpoints listed above. The JWKS endpoints include:

  • US: https://oauth.battle.net/jwks/certs
  • EU: https://oauth.battle.net/jwks/certs
  • KR: https://oauth.battle.net/jwks/certs
  • TW: https://oauth.battle.net/jwks/certs
  • CN: https://oauth.battlenet.com.cn/jwks/certs
