Getting Started

Original: https://community.developer.battle.net/documentation/guides/getting-started

Before you can get started using the APIs, you must:

  1. Login or create a new Battle.net account.
  2. Create a client through the API Access menu option.
  3. Generate a secret for the client.
  4. Understand how the APIs work with OAuth.
  5. Learn how to make API requests.

Log in or register an account

Before you can use any of the APIs, you need to log in to your Battle.net account or, if you don't have one, create a new one.

Next, attach a Battle.net Authenticator to your account. Two-factor authentication is required for any API usage; this keeps your account secure and protects the API data.

You'll also need to accept the Blizzard Developer API Terms of Use before you can make any API requests.

Creating a client

To create a client:

  1. Log in to the Developer Portal and click API Access at the top of the window.

  2. Click Create New Client.

    Note: Developers are limited to 50 clients at a time.

  3. In the Client Name field, enter a name to identify your client in the list view. Client names may be visible to your site users and are globally unique across all developer accounts.

  4. In the Redirect URIs field, enter the URI to redirect the user to after they finish authorizing through the Blizzard's login page. This field is used with OAuth authentication.

  5. In the Service URL field, enter the URL of the service that will be using this client.

    Note: If you do not have a service URL, click the associated checkbox to indicate this. If you later add a service URL, you must update the client with this information.

  6. In the Intended Use field, specify how you intend to use this client. For example, your client will provide players information about their World of Warcraft characters or your client will display information about Hearthstone cards.

  7. Click Create.

Managing clients

After creating clients, users can manage their client IDs and secrets via the Manage Client page. To manage a client, go to the Clients page and click Manage Client for the desired client.

The Manage Client page displays the following information:

  • Client ID
  • Client secret
  • The option to generate a new client secret
  • Client name
  • Client redirect URIs
  • Service URL
  • Intended use of the client

Generating a new client secret

To generate a new client secret:

  1. Click Generate New Secret for the desired client.
  2. Enter a value and unit for your old secret's expiration.
  3. Click Generate.

Note that your old secret will continue to be valid for the duration of the expiration you set in step two.

Read the documentation

After creating your client ID and secret, familiarize yourself with the way OAuth and the APIs work:

  • Using OAuth provides both a quick-start and in-depth guide for implementing OAuth to work with the Developer Portal.
  • Game Data APIs describes Game Data API technical structure and World of Warcraft response structures.
  • Community APIs describes how to use Community APIs for StarCraft II and Diablo III.

Making API requests

API requests are straightforward, but there are several details to know when making requests.

Access tokens

API requests require client credentials for different types of requests. Access tokens are granted by either the OAuth client credentials flow or the OAuth authorization code flow.

Constructing a URI

URIs follow a standard syntax using the format of {region}.api.blizzard.com/{API path} (or gateway.battlenet.com.cn/{API path} for China).

For specific information about regions and locales, see Regionality and APIs.

Making the request

The following steps walk through retrieving the current price of a WoW Token by making a GET /tokenindex request.

  1. Before you make your request, follow the OAuth client credentials flow to get an access token.
  2. Make a cURL request: 
    curl -u {client_id}:{client_secret} -d grant_type=client_credentials https://oauth.battle.net/token
  3. Next, use that access token in your request: 
    curl -H "Authorization: Bearer {access_token}" https://us.api.blizzard.com/data/wow/token/?namespace=dynamic-us

The expected response follows this format:

{
    "_links": {
        "self": {
            "href": "https://us.api.blizzard.com/data/wow/token/index?namespace=dynamic-us"
        }
    },
    "last_updated_timestamp": 1536597360000,
    "price": 1138480000
}

Throttling

API clients are limited to 36,000 requests per hour at a rate of 100 requests per second. Exceeding the hourly quota results in slower service until traffic decreases. Exceeding the per-second limit results in a 429 error for the remainder of the second until the quota refreshes.
