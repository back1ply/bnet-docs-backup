Community APIs

Original: https://community.developer.battle.net/documentation/guides/community-apis

Community APIs provide a way for applications and websites to access game data about a player's account, such as characters and gameplay progress. Blizzard currently offers Community APIs for StarCraft II, and Diablo III. Developers can use APIs to retrieve the following types of game data:

  • StarCraft II: player profiles, ladder information, and match history.
  • Diablo III: player hero information, character class and skill information, and crafting recipes.

Format

APIs return data in JSON format and some responses contain resource URLs. To obtain all the desired data, API consumers must make several requests to related resources by following links in the originally requested resources.

Regions and locales

API data is limited to specific regions. For example, US APIs accessed through us.battle.net only contain US battlegroup and realm data. Locale support is limited to locations supported on Blizzard community game sites.

To access a different region, provide the locale query parameter. For example, the URL for the European Diablo III item type list localized in French uses this format:

http://eu.api.blizzard.com/d3/data/item-type?locale=fr_FR

For specific information about regions and locales, see Regionality and APIs.

Authentication and Throttling

For authentication instructions and implementation details, see Using OAuth.

API clients are limited to 36,000 requests per hour at a rate of 100 requests per second. Exceeding the hourly quota results in slower service until traffic decreases. Exceeding the per-second limit results in a 429 error for the remainder of the second until the quota refreshes.

API consumers are limited to 36,000 requests per hour at a rate of 100 requests per second.
