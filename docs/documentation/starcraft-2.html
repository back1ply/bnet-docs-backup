StarCraft II

Original: https://community.developer.battle.net/documentation/starcraft-2

StarCraft II provides APIs to access data for such things as player profiles, ladders, achivements and league data.

Before you can use the APIs, you must set up your client and secret as described in Getting Started.

API Reference

  • Community APIs — Endpoints for StarCraft II player profiles, ladder data, and achievements.
  • Game Data APIs — Endpoints for StarCraft II league data.
